{%- comment -%} Renders the byline for a research item. Front matter contract (on the _research entry): authors : list of names to print. For papers with a normal number of authors this is the complete list. For mass-authored papers it is the lead-author block only. authors_total : total number of authors. Only set when it exceeds the length of `authors`; triggers the "and N others" form. authors_all : key into _data/coauthors/.yml holding the full list. Only used on the paper's own page, behind a disclosure. Parameters: page : the post/page object to read front matter from. expandable : when true, append the full-author-list disclosure. {%- endcomment -%} {%- assign me = site.author.name -%} {%- assign lead = include.page.authors -%} {%- assign total = include.page.authors_total -%} {%- if lead and lead.size > 0 -%}

{%- for a in lead -%} {%- unless forloop.first -%} {%- if forloop.last and total == nil %} and {% else %}, {% endif -%} {%- endunless -%} {%- if a == me -%}{{ a }}{%- else -%}{{ a }}{%- endif -%} {%- endfor -%} {%- if total -%} {%- assign others = total | minus: lead.size -%} {{ " " }}and {{ others }} others, incl. {{ me }} {%- endif -%}
